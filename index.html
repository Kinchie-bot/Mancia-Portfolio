IT Troubleshooting Cases and Problem Solving

Documented IT issues, diagnostic procedures, and solutions

Case 1: Computer Cannot Connect to the Internet

Problem: The computer cannot access the internet, and websites do not load.

Possible Causes:
  • Wi-Fi is turned off.
  • The router or modem has a problem.
  • The network cable is loose.
  • The computer has incorrect network settings.
Diagnostic Procedure:
  1. Check if Wi-Fi is enabled or the Ethernet cable is connected properly.
  2. Check whether other devices can connect to the same network.
  3. Restart the router and modem.
  4. Open Command Prompt and run ipconfig to check the computer's network configuration.
  5. Test the connection by opening a website.

Solution:
Reconnect to the correct Wi-Fi network, secure the network cable, or restart the router. If the problem continues, check the network adapter settings or contact the internet service provider.

Lesson Learned: Always check the physical connections and network settings first before performing advanced troubleshooting.

Troubleshooting Case #2: Computer Runs Slowly

Problem: The computer takes a long time to start and applications respond slowly.

Possible Causes:
  • Too many applications are running.
  • The computer has insufficient RAM.
  • The storage drive is almost full.
  • Malware or unnecessary background programs are present.
Diagnostic Procedure:
  1. Open Task Manager by pressing Ctrl + Shift + Esc.
  2. Check CPU, memory, and disk usage.
  3. Identify applications using too many resources.
  4. Check available storage space.
  5. Run a security scan using trusted antivirus software.

Solution:
Close unnecessary applications, disable unneeded startup programs, remove temporary files, and uninstall unused software. If the computer still performs poorly, consider upgrading the RAM or storage drive.

Lesson Learned: Regular maintenance and monitoring help improve computer performance and prevent unnecessary slowdowns.

Case 3: Printer Is Not Printing

Problem: The printer is connected to the computer, but it does not print documents.

Possible Causes:
  • The printer is turned off or offline.
  • The paper tray is empty or paper is jammed.
  • The ink or toner is low.
  • The printer driver is outdated.
  • Print jobs are stuck in the queue.
Diagnostic Procedure:
  1. Check if the printer is turned on.
  2. Check the paper tray and ink or toner levels.
  3. Confirm that the correct printer is selected.
  4. Check the print queue for pending documents.
  5. Print a test page.

Solution:
Turn on the printer, load paper, clear any paper jams, and replace empty ink or toner cartridges. Clear stuck print jobs and update or reinstall the printer driver if necessary.

Lesson Learned: Always check the printer's physical condition, connections, and settings before replacing any hardware.

Case 4: Computer Cannot Detect a USB Flash Drive

Problem: The computer does not recognize a USB flash drive when it is plugged in.

Possible Causes:
  • The USB port is damaged.
  • The flash drive is faulty.
  • The USB driver has a problem.
  • The drive has no assigned drive letter.
  • The file system is corrupted.
Diagnostic Procedure:
  1. Remove the flash drive and reconnect it.
  2. Try another USB port.
  3. Test the flash drive on another computer.
  4. Open Disk Management in Windows to check whether the drive appears.
  5. Check Device Manager for USB-related errors.

Solution:
Try another working USB port, restart the computer, or update the USB device driver. If the drive appears in Disk Management without a drive letter, assign one if appropriate. If the files are important, avoid formatting the drive because it may erase data.

Lesson Learned: Test the device and USB port first. Always protect important files before attempting repairs that could cause data loss.

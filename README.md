# Alex Rivera — BSIT Portfolio

A responsive student portfolio built with plain HTML, CSS, and JavaScript. It includes a project filter, detail modals, a mobile navigation menu, and a small live activity message.

## Run locally

Open `index.html` in a modern browser. No build step or dependencies are required. The Google Fonts connection is optional; system fallbacks are included in the stylesheet.

## Make it yours

1. Update the name, bio, university, location, and project details in `index.html` and `script.js`.
2. Replace `assets/profile.svg` with your own portrait, then update the image `src` and alt text in `index.html`.
3. Change `hello@example.com` to your email address and add links to your real project demos or repositories.
4. Adjust the colors and typography at the top of `style.css`.

The certifications section includes certificate images and PDF records stored in `assets/`. Add more images to `assets/` and replace a `.certificate-placeholder` block with an `<img class="certificate-image" src="assets/your-certificate.jpg" alt="Description of certificate">`, then update the title below it.

All project visuals are made with HTML and CSS, so you can edit them without external image files. The example projects and contact details are placeholders; update them before publishing.
